# Vobiz Homebrew tap

Homebrew formulae for [Vobiz](https://www.vobiz.ai) tools.

```sh
brew tap vobiz-ai/tap
brew install vobiz
```

| Formula | What it installs |
|---|---|
| `vobiz` | The Vobiz CLI (coming soon). Source: [vobiz-ai/Vobiz-CLI](https://github.com/vobiz-ai/Vobiz-CLI) |

Formulae in this tap are updated automatically by the release workflow of each tool's repository.
